这是一个基于iOS无根或隐跟越狱环境的工具
1.动态白名单 动态白名单会周期性的循环刷新设备信息和按规则动态清理无用的文件标识符残留剪贴板等信息 1分钟刷新一次设备广告标识符
2.清理风险残留 一键深度清理设备的无用的文件标识符残留剪贴板等信息 拦截下发权限 刷新标识符 阻断应用追踪
3. keychain-2.db锁定 会将root下的keychain-2.db锁定成只读取规则文件的状态 同时阻断并拦截写入权限 包含严格的设备保护规则
3.清理keychain 一键执行深度规则扫描并清理应用的钥匙链残留和var下无用文件 阻断设备信息标记
4.屏蔽hook检测 通过动态断网规则阻断部分可能的hook检测和文件完整性检测
5.修复守护进程 修复被误杀的系统进程
6.支持roothelper模式和内核模式
7.自动检测设备信息
